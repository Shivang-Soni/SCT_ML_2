# Customer Segmentation with K-Means Clustering

## Project Overview
This project is part of my Machine Learning internship at Skillcraft Technologies.  
The goal is to segment customers of a retail mall based on their purchase behavior, income, and spending patterns using K-Means clustering.

The project demonstrates:  
- Practical application of unsupervised machine learning  
- Data preprocessing and feature engineering  
- Model evaluation and visualization of clusters  

---

## Challenge
To make it practical and agile:  

- Load the dataset and perform basic EDA (Exploratory Data Analysis)  
- Preprocess features (e.g., scaling, encoding)  
- Apply K-Means clustering to segment customers  
- Visualize clusters in 2D (e.g., Annual Income vs Spending Score)  
- Optionally, use Elbow method to determine optimal number of clusters  

---

## Dataset
Mall Customer Dataset (Kaggle link: https://www.kaggle.com/vjchoudhary7/customer-segmentation-tutorial-in-python)  
- Contains information for 200 customers  
- Columns include:  
  - CustomerID  
  - Gender  
  - Age  
  - Annual Income (k$)  
  - Spending Score (1-100)  

Goal: Group customers into clusters (e.g., high spenders, low spenders, etc.)

---

## Approach
- Load and preprocess data using Python (pandas, numpy)  
- Train K-Means model (scikit-learn)  
- Visualize results using matplotlib and seaborn  
- Evaluate clusters for insights (e.g., customer segmentation for marketing strategies)  

---

## Key Learning Outcomes
- Hands-on experience with unsupervised learning  
- Feature engineering and handling real-world retail data  
- Visual interpretation of clusters  
- Understanding how clustering can guide business decisions
